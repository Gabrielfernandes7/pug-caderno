# Caramelo Enciclopédia

Este repositório contém uma coleção de artefatos pedagógicos gerados por um pipeline de compilação de intenção pedagógica, que transforma frases em linguagem natural em arquivos `index.pug` autocontidos, seguindo rigorosamente oito cláusulas não negociáveis para garantir a qualidade e a eficácia do ensino.
